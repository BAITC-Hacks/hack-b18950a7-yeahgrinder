# SupplyAI — frontend demo

Светлый интерфейс закупок с Liquid Glass на навигации. Без сборки и внешних CDN.

## Запуск

```sh
.venv/bin/uvicorn api:app --port 8000   # из корня репозитория
```

Открыть http://127.0.0.1:8000. Страницу и данные отдаёт `api.py`: товары — `GET /ui/data`
(расчёт `engine/` через `web_data.py`). Если API недоступен (например, страница открыта через
`python3 -m http.server`), интерфейс показывает демо-набор из `mockDashboard.js` и плашку
«Демо-данные».

## Возможности

- KPI по поставщикам: к заказу, критично, критично и ничего нет в пути, разовые сделки исключены, сумма ₸ (SE).
- Фильтры: поставщик, категория, товар в пути, разовая сделка, категория важности.
- Утверждение с ФИО; экспорт XLSX (лист «Заказ» + лист «Утверждение») и CSV.
- Обзор: сводка по всем товарам двух поставщиков (3 561 на текущей выгрузке).
- Закупки: поиск, фильтры, выбор товаров, общая карточка рекомендации.
- Карточка: разбор количества, история и прогноз, кейсы LOOP и восстановленного спроса, оговорки.
- Ручные количества и комментарии, отклонение, черновик по поставщикам.
- Локальное подтверждение и настоящий XLSX с утверждёнными ненулевыми количествами.
- Каталог товаров и состояние демонстрационных источников.
- Два сценария: базовый и прирост +20% — оба посчитаны движком; покрытие, срочность и графики — базового.

## Файлы

- `index.html` — оболочка и навигация.
- `styles.css` — оформление и адаптивные состояния.
- `app.js` — представления и взаимодействия.
- `mockDashboard.js` — провайдер данных (`/ui/data`) и демо-набор на случай, если API недоступен.
- `export.js` — формирование XLSX (OOXML / ZIP) без сетевых зависимостей.

Правки сохраняются в localStorage этого браузера, ключ `supplyai-demo-v2`. Их можно сбросить через «Настройки → Локальные данные». Любая правка черновика отменяет подтверждение. Заказы никуда не отправляются.

Контракт данных — `docs/prompts/FRONTEND.md`, раздел «Данные». Если у товара разовая сделка или
дефицит были давно (например, «Петля LOOP», июнь 2025), график показывает архивное окно вокруг
события.
