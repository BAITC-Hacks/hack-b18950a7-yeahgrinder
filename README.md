# SupplyAI — frontend demo

Светлый интерфейс закупок с Liquid Glass на навигации. Без backend, сборки и внешних CDN.

## Запуск

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765. Нужен локальный HTTP-сервер: ES-модули не запускаются через `file://`.

## Возможности

- Обзор: согласованная сводка по 12 демонстрационным товарам двух поставщиков.
- Закупки: поиск, фильтры, выбор товаров, общая карточка рекомендации.
- Карточка: разбор количества, история и прогноз, кейсы LOOP и восстановленного спроса, оговорки.
- Ручные количества и комментарии, отклонение, черновик по поставщикам.
- Локальное подтверждение и настоящий XLSX с утверждёнными ненулевыми количествами.
- Каталог товаров и состояние демонстрационных источников.
- Два фиксированных сценария: базовый и прирост +20%. Это не расчётный движок; покрытие, срочность и графики остаются базовыми.

## Файлы

- `index.html` — оболочка и навигация.
- `styles.css` — оформление и адаптивные состояния.
- `app.js` — представления и взаимодействия.
- `mockDashboard.js` — централизованные fixtures и async data provider для будущей замены источника.
- `export.js` — формирование XLSX (OOXML / ZIP) без сетевых зависимостей.

Правки сохраняются в localStorage этого браузера, ключ `supplyai-demo-v2`. Их можно сбросить через «Настройки → Локальные данные». Любая правка черновика отменяет подтверждение. Заказы никуда не отправляются.

API-контракт не зафиксирован. При интеграции согласовать поля, срочность, горизонты, источники данных и методы сохранения решений с backend-командой. Демонстрационный график LOOP отдельно помечен как архивный кейс 2025 года.
