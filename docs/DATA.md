# Данные партнёра: IEK.zip

Поставщик в выгрузке один — ИЭК (IEK/ITK). Склад один — Алматы. Распаковано в
`data/raw/IEK/` (в git не коммитим: данные партнёра). Ключ для связи файлов —
**код 1С** (вида `010500008_`). Во всех файлах в конце есть строка «Итого» — выкидывать.

## Особенности и подводные камни

- **Количество в продажах положительное** (расход). 115 строк с минусом — старые 2023 г.
  и возвраты; 3+3 строки «Приходная накладная» / «Заказ покупателя» — мусор, отфильтровать.
- **Единицы разные**: шт / м / упак. Не суммировать между SKU без учёта единиц.
- **Реальный разовый выброс**: 09.06.2025, накладная 20000064179, «Петля металлическая
  LOOP» (130200305_) — **210 000 шт** одной строкой. Из-за неё июнь 2025 по всей компании
  = 402 тыс. шт против обычных ~200 тыс. Идеальная демонстрация must-have №4.
  Другие крупные строки (ВА47-29 25А — 7 488 шт, трубы — 3–4 тыс. м) — кандидаты на проверку.
- **Нет ID клиента и нет цены** в строках продаж, хотя кейс их упоминает. Разовые заказы
  выявляем по размеру строки/накладной относительно типичной для SKU, а не по клиенту.
  Вопрос партнёру: можно ли получить обезличенный ID контрагента.
- **Нет явного файла stockout.** Выводим сами: месяц с нулевым/пустым начальным остатком
  у SKU с историей продаж + провалы в ежедневных продажах. В кейсе он назван входом —
  вопрос партнёру.
- **Текущий остаток** точно не известен: есть только начало сентября 2026, приходов нет.
  Оценка: остаток на 01.09 − продажи с 01.09 по 22.09 (+ пришедшее, если узнаем).
- **Сроки поставки** явно не даны, но выводятся из «Пути»: дата заказа → «поступление до».
  РФ-заказы ≈ 35–40 дней, прочие ≈ 12–24 дня.
- **Категорий нет отдельным полем.** Гипотеза: префикс кода 1С — товарная группа
  (все `0105xxxxx` — ВА47-29, `1303xxxxx` — гофротрубы). Проверить перед использованием.
- **Сезонность дана на уровне компании** в деньгах, не по SKU. Для SKU с короткой
  историей — брать её (или по группе), для SKU с 2 годами истории — считать свою.
- В названиях зашита упаковка: `(12/144)` = 12 в коробке / 144 в ящике.
